## 移行の順番

LINEの応答を一度も止めないため、機能ごとに切り替える。GASとWorkerが同時に
返信すると受講者に二重で届くので、**1機能ずつ、GAS側を止めてからWorkerを有効化**する。

| 段階 | 内容 | GASを止める範囲 |
| --- | --- | --- |
| 0 | GASコードとスプレッドシートを読む。機能の棚卸し | なし |
| 1 | 過去分(8/20以降)をD1へ取り込み、画面を現在に追いつかせる | なし |
| 2 | 学校7校と今後の開催日をイベントとして登録 | なし |
| 3 | 申込フローをWorkerへ。リッチメニューの申込ボタンを差し替え | 申込のみ |
| 4 | リマインドをWorkerのcronへ | リマインドのみ |
| 5 | 初回アンケート・講義アンケートをWorkerへ | アンケートのみ |
| 6 | GASを停止。スプレッドシートは読み取り専用の保管庫にする | 全部 |

段階1と2は既存の運用に一切触れないので先に進められる。
