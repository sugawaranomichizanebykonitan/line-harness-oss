## 使える土台 (すでに実装済み・本番未使用)

イベント予約機能が丸ごと揃っており、本番のレコード数は0。**WAHMSの講義に
そのまま流用できる**。既存データを壊さずに作り込める。

| 既存テーブル | WAHMSでの意味 |
| --- | --- |
| `events` | 学校 (マーケティング学校 など7校) |
| `event_slots` | 各回の開催日時 (starts_at / ends_at) |
| `event_bookings` | 申込。status に `attended` があり実参加も扱える |
| `event_booking_reminders` | リマインド予約と送信済み管理 |

付随して次も実装済み。

- 申込用のLIFF画面 (`apps/worker/src/client/event-booking`)
- 管理画面 (`apps/web/src/app/events`)
- cronによるリマインド送信 (前日18:00 JST + 指定時間前)
- 自動応答 (`auto-replies`)、リッチメニュー管理、フォーム、シナリオ配信

### 足りないもの

- `event_slots` に「第◯回」「テーマ」を持つ列が無い → 追加が要る
- 友だち追加時の初回アンケート → `forms` で作れるが、設問の移植が必要
- 講義アンケート → Web版は実装済み。LINE内から回答する導線は未整備
- **GASのコードを未読**。機能の取りこぼしを保証できない

## 移行の順番

LINEの応答を一度も止めないため、機能ごとに切り替える。GASとWorkerが同時に
返信すると受講者に二重で届くので、**1機能ずつ、GAS側を止めてからWorkerを有効化**する。

| 段階 | 内容 | GASを止める範囲 |
| --- | --- | --- |
| 0 | GASコードとスプレッドシートを読む。機能の棚卸し | なし |
| 1 | 過去分(8/20以降)をD1へ取り込み、画面を現在に追いつかせる ✅**完了 2026-08-25** | なし |
| 2 | 学校6校と今後の開催日をイベントとして登録 ✅**完了 2026-08-25** | なし |
| 3 | 申込フローをWorkerへ。リッチメニューの申込ボタンを差し替え | 申込のみ |
| 4 | リマインドをWorkerのcronへ | リマインドのみ |
| 5 | 初回アンケート・講義アンケートをWorkerへ | アンケートのみ |
| 6 | GASを停止。スプレッドシートは読み取り専用の保管庫にする | 全部 |

段階1と2は既存の運用に一切触れないので先に進められる。
